**English**

### type some texts. hit Apply. It's easy, isn't it?

**Edit display entities(text display, block display, item display) with a real GUI instead of long /data merge commands.**

In Creative mode, look at a text display and press **G key**. A clean editor with a live preview opens, where you can tweak its text, colors, size, alignment and more.

----
## Requirements & permissions

- **Fabric Loader** and **Fabric API**
- **Creative mode** is required to open the editor.
- Changes are applied by sending `/data merge entity` and `/data remove entity` commands (and `/kill` for deleting), so you need the permission to run them:
  - **Singleplayer:** cheats must be enabled.
  - **Multiplayer:** you need operator permissions, and the server must allow those commands.

**한국어**

### 텍스트를 입력하고 적용을 누르세요! 어때요 참 쉽죠?

**길고 복잡한 /data merge 명령어 대신, GUI로 디스플레이 엔티티(텍스트 디스플레이, 블록 디스플레이, 아이템 디스플레이)를 편집하세요.**

크리에이티브 모드에서 텍스트 디스플레이를 바라본 채 **G키**만 누르면, 실시간 미리보기가 포함된 깔끔한 편집기가 열립니다. 여기서 텍스트, 색상, 크기, 정렬 등을 자유롭게 조정할 수 있습니다.

----
## 요구 사항 및 권한

- **Fabric Loader**와 **Fabric API**
- 편집기를 열려면 **크리에이티브 모드**가 필요합니다.
- 변경 사항은 `/data merge entity` 및 `/data remove entity` 명령어(삭제 시에는 `/kill`)를 전송하는 방식으로 적용되므로, 해당 명령어를 실행할 권한이 필요합니다.
  - **싱글플레이:** 치트가 활성화되어 있어야 합니다.
  - **멀티플레이:** 관리자(operator) 권한이 필요하며, 서버에서 해당 명령어를 허용해야 합니다.
